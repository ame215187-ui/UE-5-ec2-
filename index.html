UE5 EC2 — Anti-infectieux et antibiorésistance (Yasukawa) — analyse des annales

Base : 53 entrées dans UE5EC2_questions.json : 21 QCM « YASU ATBR Annales » + 13 QCM « YASU UE5 EC2 tests microbiens » (banques diffusées par la corpo 2024-25, reprises telles quelles à l'examen) + 18 QCM/QO Alauzet 2014-2016 sur les antibiotiques (ancienne UE1 EC1, même matière) + 1 entrée « format 2025 ». Sources : Drive Corpo « ANNALES D1/Sujets annales » (YASU ATBR Annales.pdf, YASU UE5 EC2 tests microbiens Annales.pdf — identiques aux deux PDF déjà dans ton dossier UE05) ; fichiers étudiants « UE5 EC2.odt » et « UE5 EC2 test microbien.odt » (Corpo 24-25, surlignages verts + « Info Yasu ») ; recueil 2013-23 p. 6-32 (Alauzet) ; recueil 2025-26.

1. Format de l'épreuve

  • MCC 2026-27 : écrit 0h30, coef 1, dans l'UE5 (NC < 10). Enseignant unique : Yasukawa (5 h anti-infectieux + 1 h tests biologiques/microbiologiques).
  • « Info Yasu » (fichier étudiant 2024-25) : « 20 questions à l'avance ; 17 questions pour ce cours et 3 pour la microbio » → 20 QCM à 1 pt : 17 sur les anti-infectieux (banque de 21) + 3 sur les tests microbiens (banque de 13). Même logique qu'en EC1 : il donne sa banque « à l'avance » et pioche dedans.
  • Déc. 2025 : les D2 n'ont rien noté pour l'EC2 dans le recueil 2025-26 (rubrique vide) — signe que le sujet n'a pas surpris (= la banque).
  • Historique : avant la réforme, les antibiotiques étaient posés par Alauzet dans l'ancienne UE1 EC1 (15 QCM + 2 QO entre 2014 et 2016 : mécanismes d'action, résistance, critères de choix, antibioprophylaxie, antibiothérapie curative, métronidazole). Rien de connu 2017-2023 pour cette matière.
  • Attendu le 16 décembre 2026 : 20 QCM (3-4 items, 1 à 4 réponses justes), 30 min, dont ≥ 15 repris mot pour mot des deux banques. Risque : quelques questions neuves sur le cours 2026 (complément « 2 - anti-infectieux complément », BMR, One Health, antibiogramme).

2. Qui pose quoi

  • Yasukawa, banque « ATBR » (21 QCM) : définitions (antibiotique, Waksman 1943, CMI, spectre), classification (structure / cible), cibles (paroi, protéines, acides nucléiques — familles correspondantes), mécanismes de résistance (efflux, mutation, inactivation enzymatique, substitution de cible), risques de la prescription / One Health, bon usage (monothérapie, réévaluation à 48 h, infections avérées), chiffres SPF 2024 (amoxicilline 69 %, amox-clav 16 %, dentistes 12,5 % des prescriptions, 65-79 ans, PACA-Corse), molécules de référence (amoxicilline en curatif 7 j et en prophylaxie, azithromycine 3 j).
  • Yasukawa, banque « tests microbiens » (13 QCM) : objectif des tests (identifier le pathogène), S. mutans / lactobacilles en cariologie, parodontopathogènes (P. gingivalis, P. intermedia, T. denticola, F. nucleatum), tests salivaires (bactéries cariogènes, flux, pH), culture/numération, PCR temps réel (sonde TaqMan), E-test pour la CMI, tests génétiques en parodontologie.
  • Alauzet (2014-2016, même matière) : QCM 5 items recyclés : bêta-lactamines = paroi (pas membrane), glycopeptides inactifs sur Gram − (membrane externe), métronidazole activé dans le cytoplasme / anaérobies, résistance naturelle vs acquise, pression de sélection, bêta-lactamases + acide clavulanique, critères de choix (spectre étroit, concentration au foyer, effets secondaires, terrain), antibioprophylaxie (patients à risque d'EI, dose unique d'amoxicilline, pas pour prothèse articulaire), antibiothérapie curative (7 j, amoxicilline/clindamycine, parodontite nécrosante ; pas pour les caries). QO 2015 : métronidazole (mécanisme, spectre, résistance POR).

4. Récurrences

  • Alauzet recyclait 3 stems à chaque session 2014-2016 (« bêta-lactamines… membrane/paroi », « résistance naturelle/acquise… », « critères de choix… ») : ce sont exactement les notions des QCM 1, 2, 3, 5 de la banque ATBR → questions quasi certaines.
  • Dans la banque, les chiffres SPF 2024 sont posés deux fois sous deux angles (molécules les plus prescrites + % amoxicilline ; % amox-clav) ; la durée de traitement est posée deux fois (amoxicilline 7 j, azithromycine 3 j) ; CMI posée deux fois (définition + E-test).

5. Jamais tombé (programme 2026-27)

  • Antibiogramme en pratique (lecture des diamètres, concentrations critiques), BMR (SARM, EBLSE, entérocoques résistants…), concept One Health détaillé, antifongiques/antiviraux (si traités dans « anti-infectieux »), paramètres PK/PD (temps- vs concentration-dépendant, CMB, effet post-antibiotique) : dans le cours 2026 mais absents des banques → c'est là que viendront les 3-5 questions neuves. Lire le « complément » (cours n°2) et le PDF du 30.09.2026.

6. Stratégie (30 min, 20 QCM)

  1. 1 h : faire les 34 QCM des deux banques avec la clé du JSON ; vérifier dans le cours les 8 items marqués « à vérifier / probable » (chiffres SPF 2024, tranches d'âge, région, classification, lactobacilles Q9 : le fichier étudiant surligne « gingivites », presque sûrement une erreur → caries).
  2. 45 min : fiche d'une page : familles → cible → bactéricide/statique ; 4 mécanismes de résistance (+ imperméabilité) ; CMI/CMB/E-test ; Waksman 1943 ; SPF 2024 (69 % / 16 % / 12,5 % / 65-79 ans / PACA-Corse) ; amoxicilline 2 g prophylaxie, 7 j curatif, azithromycine 3 j, clindamycine 600 mg si allergie ; réévaluation à 48 h ; monothérapie.
  3. 45 min : lire une fois le complément 2026 (BMR, One Health, antibiogramme) et en tirer 10 QCM perso.
  4. J-3 : refaire les 34 QCM en 15 min chrono ; J-1 : relire la fiche. Objectif ≥ 17/20.

7. Qualité des sources

  • Les deux banques n'ont aucune clé officielle : la clé du JSON est proposée par l'IA (niveau de confiance indiqué) + 2 items surlignés dans « UE5 EC2.odt » (Waksman, amoxicilline prophylaxie) + les surlignages de « UE5 EC2 test microbien.odt » (fichier étudiant, 1 surlignage douteux : lactobacilles → gingivites).
  • Aucun sujet réel de l'EC2 n'est connu mot pour mot (ni 2024, ni 2025) ; seule l'« Info Yasu » documente le format (17 + 3).
  • Les QCM Alauzet 2014-2016 n'ont pas de corrigé officiel (clés probables).
  • Le cours 2026-27 (3 fichiers) n'a pas été lu : les notions « jamais tombées » sont déduites du livret.
